# Test fixtures

`sample.docx` is a synthetic Word document generated for the DOCX import tests
(`T-3.8.2`). It contains:

- a Title and a Heading 1/2;
- paragraphs with bold and italic runs;
- Spanish accents and an em dash;
- a small table;
- a tiny image.

It is not based on any real manuscript. The image is the placeholder app icon
used only to verify that images are dropped and counted.
